# 0001: Feature construction is closed by evidence, not inertia

**Decision:** Further feature depth requires evidence that the feature-complete contract is false, or an explicit scope revision.  
**Alternatives rejected:** continuing to deepen systems because each one is technically plausible.  
**Why:** [policy: specification/GameCompletionDefinition.md] states the stop condition and says to answer which intended role is still shallow.  
**Revisit when:** human playtesting shows a concrete gap, or the owner revises scope. (open: owner decision)
