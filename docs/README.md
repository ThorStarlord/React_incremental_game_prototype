# Repository Documentation

Start with [`CURRENT.md`](CURRENT.md).

`CURRENT.md` is the canonical classification index for deciding whether a repository document is **CURRENT AUTHORITY**, **REFERENCE**, **HISTORICAL EVIDENCE**, or **SUPERSEDED**.

The `docs/analysis/` directory contains earlier analysis material. It is preserved for provenance and reference; it is not current repository-state authority unless a current authority document explicitly promotes a specific conclusion.

Top-level roles:

- [`../STATUS.md`](../STATUS.md) — current repository/milestone truth;
- [`CURRENT.md`](CURRENT.md) — documentation authority and supersession;
- [`../RUNBOOK.md`](../RUNBOOK.md) — operational and CI procedure;
- [`../README.md`](../README.md) — repository orientation;
- [`../specification/README.md`](../specification/README.md) — domain-specific technical/product authority map.

Do not physically reorganize historical evidence merely for neatness. Prefer explicit classification so old links, PR evidence, and chronology remain stable.
