# Campaign One 1.1 — Release Notes (candidate; NOT YET RELEASED)

**Release status:** CANDIDATE IN DEVELOPMENT / NOT QUALIFIED. The shipped game remains `1.0.0`.

## Intended 1.1 improvement

Version 1.1 makes Traits patterns the protagonist can learn, assimilate, keep, selectively express and suppress. This revision is intended to make character growth more flexible and tangible while preserving Campaign One's relationship-driven progression, remembered narrative history, and bounded Copy delegation.

The proposed release includes:

- Universal Trait identity metadata that distinguishes cognitive, physical/procedural, knowledge and metaphysical natures without locking the world into a closed Trait taxonomy.
- Permanent assimilated Trait library independent of two initially available expression slots and later unlocks.
- Free, player-owned Trait expression/suppression without NPC proximity, including expression-aware authored requirements, combat/Quest/dialogue consumers and shared Copy traits.
- Doctrine focus requiring assimilated, expressed and foregrounded Traits.
- Essence Stabilization that preserves already expressed Traits and enables repeatable Copy calibration through actual Player learning.
- Save-schema v3 migration supporting eligible `1.0.0`/schema-v2 saves.
- Small bounded procedural Attack Trait advantage in the existing Strike combat option, with the ordinary no-Trait route preserved.
- Revised player-facing Trait wording and keyboard-accessible controls.

## What does not change

Campaign One still covers the Prologue, Chapters 1–7, Telluric Echo finale and its epilogue. This is not a generic crafting/combat overhaul, interplanetary expansion, new campaign, or open-ended autonomous Copy planner.

## Compatibility and supported clients

The intended target is current desktop Chromium-class browsers and Firefox, at 1280x720 minimum. Player progress remains locally stored. Export saves before replacing a build; supported schema-v2 saves should migrate once to v3, subject to release qualification.

## Evidence / limitations

**This candidate has not been externally playtested.** No claim is made that other players find Trait expression intuitive, balanced or enjoyable. Technical CI, synthetic UI tests and internal documentation do not replace actual human sessions. The official 1.0.0 release and qualification records remain unchanged.

**Do not publish these candidate notes as a completed 1.1 release** until `docs/release/Version11CandidateResult.md` records a qualified exact build and the separately authorized release decision.
