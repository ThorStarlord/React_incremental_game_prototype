# GC-10 Telluric Echo Finale + Epilogue Preregistration

**Status:** IMPLEMENTATION PREREGISTRATION  
**Program:** Campaign One / 1.0 Game Completion  
**Prepared:** 2026-09-20

## Function

Provide a legal Campaign One end condition that consumes accumulated state and produces a state-responsive epilogue without inventing a finale engine, readiness score, or autonomous resolution path.

## Entry

GC-09 has manually committed exactly one persisted `counterphasePlan`:

```text
distributed | structural | fortified | diagnostic
```

and its route-specific Lyra preparation Memory exists.

## Finale execution

Lyra exposes one authored finale-entry dialogue matching the committed plan.

That dialogue:

- requires the matching GC-09 commitment Experience;
- requires matching `counterphasePlan` World State;
- for the fortified route, re-checks City Watch institutional standing;
- unlocks exactly one route-specific Telluric Echo finale Quest.

Four route-specific finale Quests use the existing Quest authority:

### Distributed

- baseline-capable;
- no requirement to own every optional capability;
- broad verified network deployment.

### Structural

- requires active `structural_steward` doctrine, derived from permanent `WillowsWisdom + ConstraintSense`;
- uses load-bearing network paths;
- represents carrying the foregrounded structural posture into the finale rather than merely proving the pair was learned once.

### Diagnostic

- requires active `countermodeler` doctrine, derived from permanent `ScholarlyInsight + AdversarialCalibration`;
- uses prediction/contradiction sensing;
- represents carrying the foregrounded diagnostic posture into the finale rather than merely proving the pair was learned once.

### Fortified

- no optional Trait pair required;
- institutional logistics remain separately gated by Faction standing.

Copies cannot start, resolve, or commit the finale Quest.

## Persisted campaign completion

After a legal finale Quest resolution, a route-specific Lyra aftermath dialogue records both completion fields on the existing Telluric Echo region, `location_whispering_woods`:

```text
campaignStatus = complete
```

and one categorical objective consequence:

```text
telluricEchoOutcome =
  distributed_dissipation |
  structural_redirection |
  diagnostic_disruption |
  fortified_containment
```

The same action records:

- `fact_gc10_campaign_complete` on Lyra;
- route-specific defining Relationship evidence;
- a player-visible finale Memory.

These are persisted through existing World State / Knowledge / Relationship save authority. There is no new campaign-save root.

## Epilogue projection

The normal UI epilogue is a pure projection of canonical state and must reflect at minimum:

- Lyra finale/relationship interpretation;
- Elara callback;
- one additional Chapter 1 / network anchor callback (Gronk or Valerius, based on actual history);
- City Watch institutional standing;
- `latticeIntegrity`, `networkPosture`, `counterphasePlan`, and `telluricEchoOutcome` where present;
- capability/build contribution from the committed plan;
- mastered routine / Copy delegation state where relevant.

The epilogue must not fabricate callbacks for evidence the player never recorded.

## Causal presentation

Use player-visible Memories and canonical state to explain the ending. Do not reveal hidden authoring-only state or infer motives.

## Exit

Campaign One is complete when:

- a route-specific finale resolution Experience exists;
- route-specific epilogue Experience/Memory exists;
- `campaignStatus = complete`;
- `telluricEchoOutcome` matches the committed plan;
- `fact_gc10_campaign_complete` exists;
- normal UI renders the state-responsive epilogue.

## Negative paths

- no finale auto-resolution by Copy/offline progress;
- no requirement to collect every optional capability;
- no universal readiness currency;
- no generic FinaleEngine;
- no ChapterEngine / narrative DSL;
- no epilogue text based on unrecorded optional history.
