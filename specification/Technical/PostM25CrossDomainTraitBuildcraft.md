# Post-M25 Cross-Domain Trait Buildcraft

**Status:** REPOSITORY-ONLY / HERMETIC QUALIFICATION  
**Human product-value evidence:** UNPROVEN

## Purpose

Deepen relationship-derived Traits as durable capability identities rather than interchangeable numeric bonuses.

The repository already qualifies `ScholarlyInsight` as a Trait-gated investigation/Quest resolution in `quest_m16_impossible_inventory`. This package adds a second, tactical consumer using the existing combat capability gate.

```text
Relationship history with Elara
-> permanent ScholarlyInsight authority
-> investigation: reopen a contradictory model
-> combat: challenge incompatible field readings
```

## New bounded combat case

`CONTRADICTION_ECHO_ENCOUNTER` exposes two semantic actions only to permanent `ScholarlyInsight` owners:

- `Challenge the Model`
- `Exploit the Contradiction`

The special route uses the same existing `TraitCapabilityRequirements` enforcement as M17. It does not inspect Connection, Affinity, Trust, or other Relationship values directly.

Ordinary `Strike` and `Guard` remain available, so the Trait expands solution space rather than making baseline play invalid.

## Distinct capability identity

The existing Willow case reads a repeating causal cycle and disrupts it at release. The Scholarly Insight case identifies incompatible models and exploits the contradiction during building. They intentionally use different labels and tactical windows despite sharing the same bounded combat feedback mechanism.

## Evidence ceiling

This package qualifies the combat engine application and cross-domain semantic contract. It does not claim that the new encounter is routed into a complete player-facing chapter, that players recognize the semantic distinction, or that the resulting buildcraft is fun or desirable. Those remain later content/product evidence questions.
