# GC-09 Chapter 7 Preregistration — Counterphase

**Status:** IMPLEMENTATION PREREGISTRATION  
**Program:** Campaign One / 1.0 Game Completion  
**Prepared:** 2026-09-20

## Function

Convert accumulated campaign history into explicit finale preparation without inventing a universal readiness score.

Chapter 7 reads canonical state already produced by prior chapters:

- Relationship / Memory history;
- permanent relationship-derived capabilities;
- per-NPC Knowledge;
- Faction reputation;
- objective World State (`latticeIntegrity`, `networkPosture`);
- personally mastered routines and bounded Copy work.

## Entry

One GC-08 network commitment exists:

```text
distributed | structural | fortified | diagnostic
```

and its route-specific Lyra commitment Experience/Memory is present.

## Preparation profiles

Chapter 7 exposes authored final-preparation options based on existing canonical state rather than synthesizing `finaleReadiness`.

Minimum legal profiles:

### Distributed counterphase

- available from `networkPosture = distributed`;
- baseline-capable;
- uses verified broad deployment;
- does not require every optional Trait.

### Structural counterphase

- available from `networkPosture = structural`;
- materially benefits from `WillowsWisdom + ConstraintSense`;
- preparation emphasizes load-bearing response paths.

### Diagnostic counterphase

- available from `networkPosture = diagnostic`;
- materially benefits from `ScholarlyInsight + AdversarialCalibration`;
- preparation emphasizes prediction/contradiction sensing.

### Fortified counterphase

- available from `networkPosture = fortified`;
- depends on the already-recorded institutional support path;
- Faction state remains independently visible rather than being folded into Relationship.

At least two profiles must remain legally finale-enterable in representative valid campaign histories.

## Player-facing causal explanation

Before commitment, normal UI must explain why available preparation options exist using already-visible causal evidence:

- route Memory;
- current network posture;
- permanent capabilities;
- known institutional standing;
- mastered routine/delegation state where relevant.

Do not reveal hidden future outcomes or calculate a single score.

## Copy authority

Copies may execute only already-mastered safe routine work such as:

- `archive_verification`;
- `resonance_calibration`;
- `forge_assistance` where location/role permits.

Copy completion may contribute its existing bounded economy effect. It may not:

- choose a preparation profile;
- set final commitment state;
- create finale-entry Relationship evidence;
- auto-brief NPCs;
- auto-resolve the Telluric Echo.

## Manual final commitment

The final preparation commitment is an explicit player action on a Lyra-owned authored dialogue.

The commitment reads prior state and records:

- exactly one preparation profile Experience;
- a durable player-visible Memory;
- a bounded categorical World State `counterphasePlan` describing the selected preparation profile.

Proposed values:

```text
distributed | structural | fortified | diagnostic
```

`counterphasePlan` is an authored categorical decision, not a readiness currency.

All competing commitment dialogues share a forbidden Knowledge fact such as:

```text
fact_gc09_finale_commitment_made
```

so the first manual commitment closes the others through existing Knowledge authority.

## Exit

Chapter 7 completes when:

- one legal final preparation profile is manually committed;
- its Relationship/Memory evidence exists;
- the matching `counterphasePlan` World State exists;
- the shared commitment fact exists;
- normal UI exposes the finale as next.

## Negative paths

- no `finaleReadiness` number;
- no preparation planner;
- no auto-selection from network posture;
- no Copy-created final commitment;
- no requirement to own every capability;
- no ChapterEngine / narrative DSL;
- no finale auto-resolution.
